## 3. 三个核心算法怎么做的

### 3.1 场结构判定（`field_analyzer`）

两个互补判据，都是为了避开"把纹理当梳齿"这个经典误判：

**判据一：梳齿像素占比**
对每个像素取上下相邻行（隔行帧中这两行属同一场，当前行属另一场），
判定它是否为"单行尖刺"：

```
mid = (above + below) / 2
若 |cur - mid| > 阈值 且 (cur - above) * (cur - below) > 0  →  梳齿
```

后半个条件很关键：它排除了斜坡纹理（天然高行差），只保留真正的隔行形态。

**判据二：场间/场内行差比**
跨 1 行（异场）与跨 2 行（同场）的平均差之比。逐行素材约 0.6—1.0，
隔行运动素材 > 1.15。为避免高细节素材误判，阈值按实测细节能量动态抬高。

**telecine 判定（更硬的一条）**
不靠重复帧，而靠**单场重复**：3:2 pulldown 会让"某一场与前一帧同场几乎相同"，
而真隔行（摄像机拍摄）几乎不会整场重复。
实测比例落在 25%—60% 判定为 pulldown（理论值 40%）。

### 3.2 颗粒估计（`grain_policy`）

先按 16x16 分块算平均梯度，取梯度最低的 25% 作为"平坦块"，
再在这些块上算拉普拉斯响应的中位数，用 Donoho 估计换算 σ：

```
σ = median(|L|) / 0.6745 / √6
```

**为什么先筛平坦块**：直接全图取中位数会把景物纹理算成噪声，
σ 被高估 2—3 倍，回注后画面发脏。实测在纯噪声图上 σ≈3.4（理论 3.46）。

### 3.3 几何处理（最容易翻车的一处）

720x480 + SAR 8:9 的真实画面是 4:3。若直接拉到 1920x1080（16:9），
**横向被拉宽 33%，人脸变胖**——观众看得出不对，但往往说不清哪里不对。

代码里同时处理了两件事：

1. `ProcessingChain` 的放大倍数按**显示宽度**算（1920/640 = 3.0），不是按编码宽度（1920/720 = 2.67）
2. 导出时按 DAR 等比缩放后居中，两侧留黑边，**绝不拉伸**

`ChainScaleUsesDisplayWidth` 这条单测就是专门锁这个行为的。

## 4. 实测验证记录

四类素材用 ffmpeg 合成（`testdata/`），跑完整链路：

| 样本 | 构造 | 自检结论 | 客观验证 |
|---|---|---|---|
| `int_480i.mpg` | 720x480 隔行交织 TFF | interlaced，100% | 输出 24 帧 idet 全 Progressive（原片 120 帧全 TFF） |
| `sd_43.mpg` | 720x480 SAR 8:9 | progressive + SAR 严重告警 | 内容居中，左右 240px 黑边，未变形 |
| `prog_720p.mp4` | 1280x720 逐行 | progressive | 判 BT.709，不做矩阵转换 |
| `tc_ntsc.mpg` | 24p → 3:2 pulldown | **telecine，90%，可还原 24p** | 180 帧经 IVTC 变 **144 帧**，输出 23.976fps |

单元测试 **97 项全过**，覆盖 JSON、帧缓冲、宽高比、场判定、色彩推断、
颗粒估计、处理链决策、引擎放大、ffprobe 解析。

两个真实 bug 是在这轮验证中被抓到的，都不是理论问题：

1. **管道句柄提前关闭** → ffmpeg 静默退出、读到 0 字节。这类 bug 不看代码根本查不出，
   表现只是"帧数 0"。
2. **4:3 被拉伸** → 第一版导出的画面横向变形 33%，看截图才发现。

## 5. 命令行怎么用

```bat
:: 自检
lumen-probe.exe "D:\剧集\S01E01.mkv"
lumen-probe.exe movie.mp4 --json --preset quality

:: 导出（先 dry-run 看命令）
lumen-render.exe in.mkv out.mp4 --dry-run
lumen-render.exe in.mkv out.mp4 --limit 300
```

编译：双击 `build.bat`，或 `./build.sh`。

工具链用的是便携版 GCC 16.2，装在 `%USERPROFILE%\tools\mingw64`，未改系统环境变量。
