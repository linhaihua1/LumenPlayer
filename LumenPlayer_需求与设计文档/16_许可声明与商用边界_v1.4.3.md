- 项目**整体源代码公开**，采用自定许可 **LNC-SL 1.0**（LumenPlayer Non-Commercial Source License）。
- 个人学习、研究、评测、家庭使用、社区无偿共享：**免费**。

  不得只写「MIT / Apache / 开源」。

## 二、为什么不用现成许可证

| 选项 | 是否合适 | 原因 |
|------|----------|------|
| MIT / Apache-2.0 | 否 | 完全允许商用，与「商用受限」冲突 |
| GPLv2+ / AGPL | 否 | 只要求衍生品同许可证，仍允许商用；AGPL 还会传染网络服务 |
| CC BY-NC-SA | 否 | 为作品设计，含 SA 传染与不为软件设计的条款 |
| PolyForm Noncommercial | 接近 | 可考虑，但中文项目自定条款更直观、授权联系人明确 |
| **LNC-SL 1.0（自定）** | **采用** | 明确区分非商用/商用、保留第三方例外、中文可读 |

## 三、授权边界

1. **自有代码**：`src/`、`tests/`、`tools/`、`android/`、`docs/`、文档集等，
   按 `LICENSE` 授权。
2. **第三方组件**：按各自许可，不受本协议覆盖，见 `THIRD-PARTY-NOTICES.md`：
   - `mpv.exe`：GPLv2+，以独立进程 + JSON IPC 调用，未链接 libmpv；
     但单文件发布物内嵌它，仍须遵守其源码提供义务。
   - `d3dcompiler_43.dll`：微软 Windows SDK 组件，按微软条款使用。
   - ONNX Runtime C API 头文件：MIT。
   - FFmpeg / x264：仅构建测试期使用，不随发布物分发。
3. **商标**：「LumenPlayer」名称与标识保留权利，本协议不授予商标使用权。
4. **贡献**：提交 PR / 补丁即视为按本协议授权该贡献。
