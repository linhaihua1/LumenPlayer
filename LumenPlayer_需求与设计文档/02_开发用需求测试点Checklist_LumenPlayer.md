## 三、状态与权限

| 序号 | 测试点描述 | 开发自测 |

| 4.12 | 系统休眠唤醒后播放可恢复或给出明确提示 | ☐ |

## 五、性能与安全

| 序号 | 测试点描述 | 开发自测 |
|------|-------------|----------|
| 5.1 | 1080p 输出、24/30fps 片源稳态**零丢帧**（单帧预算 41/33ms，留 30% 余量） | ☐ |
| 5.2 | 掉帧率 < 0.5% / 10 分钟（HUD 统计） | ☐ |
| 5.3 | 首帧 ≤ 1.5s；冷启动到可交互 ≤ 3s | ☐ |
| 5.4 | 音画同步漂移 < 40ms，3 小时累计不恶化 | ☐ |
| 5.5 | 常驻内存 < 1.5GB；3 小时播放 + 200 次 seek 后内存增长 < 100MB（泄漏门禁） | ☐ |
| 5.6 | GPU 句柄/纹理/解码器实例数在 200 次 seek 后回落到基线 | ☐ |
| 5.7 | CPU 占用 < 25%（硬解路径）；GPU 总占用留 ≥20% 余量 | ☐ |
| 5.8 | 笔记本电池模式自动降档，续航不出现断崖式下降 | ☐ |
| 5.9 | 主程序依赖审计：无 AGPL 组件；FFmpeg 为 LGPL 配置，无 GPL 编码器 | ☐ |
| 5.10 | 播放器不发起任何网络请求（一期），抓包验证为空 | ☐ |
| 5.11 | 不读取用户目录以外文件、不上传任何文件内容 | ☐ |
| 5.12 | 画质盲测：≥5 人（含 2 名影视从业）判定无蜡像脸/振铃/纹理蠕动 | ☐ |
| 5.13 | 色域校验：BT.601 SD 片源肤色/天空色块不偏绿偏红 | ☐ |
